# Individual Technical Reflection

I chose a fintech mobile wallet as my case study because of my daily experience with mobile wallets. In real life I have watched this kind of service revolutionise and transform the Nigerian banking system as it happened.

The results surprised me a lot. Using SQL tools and setting up a GitHub repository was unknown territory for me, and I was also shocked by some of the results and outcomes I got.

The hardest part of this adventure, if I may call it that, was failing and learning to recover from that failure, all while juggling my job and focusing on this project.

If TapNaira grew to millions of customers, I would first check whether the current database is capable of handling that load, and I would look for ways to close all the loopholes.
