## Selected case study: TapNaira Wallet (simulated fintech)

TapNaira is a fictional Lagos mobile-money company. Customers keep a naira wallet on their phone, agents (POS shops) handle cash in and cash out, and admin staff handle support, KYC, fraud review and finance.

| | |
|---|---|
| **Users** | Customers (app), agents (POS app), admin staff (support, compliance, finance, super-admin) |
| **Major data** | Customers and KYC tiers, agents, wallets, transactions, a double-entry ledger, billers and bill payments, fraud flags, audit log |
| **Key operations** | **Wallet-to-wallet transfers**, cash in and cash out at agents, bill payments, reversals, wallet freezes, fraud review, statements and reconciliation |

All portfolio activities use this case study and the same synthetic dataset (about 304,000 transactions), generated by `portfolio-1-database-design/seed_data.sql`. All names in it are fictional.

